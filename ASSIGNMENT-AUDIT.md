# Assignment requirements audit

Source reviewed: Professional ePortfolio handout supplied in the local course workspace, dated August 17, 2026.

## Mandatory submission components

- [x] Digital platform with a public URL suitable for Quercus submission
- [x] Up-to-date résumé including the May–August 2026 work term
- [x] One entry for the first four-month work-term milestone
- [x] Entry title, caption, creation date, and last-updated date
- [x] Visual example of work: original public-safe knowledge retrieval process diagram
- [x] Annotation of approximately 250 words covering context, development, and outcome
- [x] Reflection explaining learning, skill development, improvements, and career relevance
- [x] Work sample directly related to the portfolio’s employer audience
- [x] Confidentiality handled through a summary and reconstructed visual rather than internal artifacts
- [x] External links checked through automated browser tests

## Rubric mapping

| Criterion | Implementation |
| --- | --- |
| Visual or multimedia work selection | The Knowledge Retrieval Prototype entry includes a purpose-built visual artifact tied directly to the work sample. Other archive entries have labelled, non-deceptive replacement frames. |
| Work-sample story | The entry describes the situation, purpose, team role, one-week scope, actions, constraints, prototype outcome, and limitations. |
| Work-term reflection | A separate reflection identifies learning, workflow improvements, developed skills, and relevance to a software-engineering career. |
| Layout and design | Responsive editorial system, semantic structure, visible focus states, tested links, mobile layouts, and restrained motion. |
| Creativity and individual expression | The archive/index concept, category-aware case studies, evidence-access system, original process visual, and editorial timeline form a coherent personal presentation. |

## Quality checks completed

- Astro and TypeScript diagnostics
- Content-schema tests
- Archive keyboard-filter test
- WCAG 2.1 A/AA automated scan on representative pages
- Reduced-motion test
- Horizontal-overflow checks at 360, 768, 1280, and 1600 pixels
- GitHub Pages base-path production build
- Downloadable letter-size résumé PDF and print stylesheet

Submit the deployed GitHub Pages URL in Quercus. If the portfolio should not be used later as a course example, state that preference in the Quercus assignment comment field as instructed by the handout.
